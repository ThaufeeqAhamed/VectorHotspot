# VectorHotspot: Dengue-Malaria Dual-Disease Spatiotemporal Early Warning System

A pipeline to forecast dengue and malaria risk in India at fine spatial resolution (H3 hexagons, ~5.2 km² each) using statistical disaggregation to bridge the gap between coarse public surveillance data and fine-grained early warning needs.

## Quick Start

### Prerequisites

```bash
# Python 3.8+
pip install pandas numpy scipy geopandas shapely h3 rasterio requests tqdm
```

### Step 1: Download WorldPop Population Data

```bash
python src/data_prep/download_worldpop.py
```

This downloads 5 GeoTIFF files (~18 MB each, ~90 MB total) for years 2000, 2005, 2010, 2015, 2020.

**Manual download (if script fails):**
- Visit: https://hub.worldpop.org/geodata/listing?id=29
- Download: India 1km Aggregated Population rasters for 2000, 2005, 2010, 2015, 2020
- Place in: `data/raw/population/`
- Files should be named: `ind_ppp_YYYY_1km_Aggregated.tif`

### Step 2: Generate Hexagon-Level Population

```bash
python src/data_prep/generate_hex_population.py
```

**Output:** `data/processed/hex_population_2000_2020.csv` (~40-50 MB)

This extracts population for each of the 620,742 hexagons using a fast bulk rasterization method. Takes ~5-10 minutes total for all 5 years.

### Step 3: Run Spatial Disaggregation Model

```bash
python src/disaggregation/wire_disaggregation_model.py
```

**Outputs:**
- `data/processed/dengue_hex_annual.csv` (~409 MB, gitignored)
- `data/processed/malaria_hex_annual.csv` (~748 MB, gitignored)
- `data/processed/disaggregation_fit_report.txt`

This disaggregates state-level dengue and district-level malaria case counts to hexagon resolution using population as a covariate, with exact mass-preservation.

## Methodology Summary

### Core Innovation: Statistical Disaggregation

Indian public dengue/malaria data is only available at coarse resolution (state/district-level). This project uses **mass-preserving statistical disaggregation** to generate fine-resolution (H3 hexagon) risk surfaces while ensuring predictions sum exactly to known coarse totals.

**Method:**
1. Fit Poisson regression at coarse (state/district) level using hexagon-level population as covariate
2. Generate hexagon-level predictions
3. Rescale predictions within each state/district so they sum exactly to the observed total

**Key Constraint:** Population enters both as:
- Multiplicative exposure offset (cases scale with population)
- Regression covariate (allows learning super/sub-linear density effects)

### H3 Resolution Decision

**Resolution 7** (~5.2 km² per hexagon, 620,742 hexagons over India)
- Chosen as close to the practical ceiling of what real covariates (1km population, ~25km rainfall, ~100km temperature) can support
- Finer than resolution 6 (~877x finer than district-level)
- Not so fine as to add row count without genuine spatial information

## Important Design Decisions

1. **Always join on (state, district) tuples** — Never use `dt_code` alone (not unique nationally)
2. **Population is currently the only covariate** — Weather reserved for temporal disaggregation/forecasting stage
3. **No synthetic data in production pipeline** — `disaggregation_prototype.py` is proof-of-concept only
4. **Large hex-annual CSVs are gitignored** — Regenerable via script, too large for version control

## Known Limitations & Bugs Fixed

### Fixed Bugs (Do Not Reintroduce):
1. ✅ Malaria data: 52% invalid (state, district) pairs due to PDF parsing → Fixed with canonical lookup (14.2% residual documented)
2. ✅ Temperature data: 66-72% null due to coarse-grid zonal-stats → Fixed with per-district pixel membership method
3. ✅ Hexagon population: 50+ min/year slowness → Fixed with bulk rasterize + bincount
4. ✅ H3 grid validation: Used district name alone → Fixed with (state, district) tuples
5. ✅ Disaggregation: Out-of-memory crash → Fixed with `.ngroup()` + memory cleanup
6. ✅ Disaggregation: BOM/encoding error → Fixed with `utf-8-sig` + column stripping

### Known Limitations:
- Case data is annual-only (temporal disaggregation planned for Phase 6)
- Population is currently the only real covariate (Tier 2 covariates planned)
- 14.2% of malaria rows have unresolved (state, district) pairs (documented, explained)
- Small systematic edge bias in hex population from "winner takes all" pixel assignment (cross-validated as acceptable)

## Validation Results

### Mass Preservation (Phase 5)
- ✅ Max absolute error: 0.000000 (exact, by construction)
- ✅ Validated across 451 dengue state-years and 14,402 malaria district-years

### Population Cross-Validation
- National-level error: 0.15%
- 75% of districts within 1.2% error
- Method validated as acceptable for disaggregation covariate

### Epidemiological Plausibility
- ✅ Dengue: Positive population coefficient (urban/high-density concentration)
- ✅ Malaria: Negative population coefficient (rural/low-density concentration)
- ✅ Visual validation: Dengue concentrated in major cities, malaria in Odisha-Chhattisgarh-Jharkhand belt
